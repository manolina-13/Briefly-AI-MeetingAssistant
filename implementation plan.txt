# Meeting Muse Implementation Plan

## 1. Project Overview
**Goal:** Build a serverless Chrome extension to record Google Meet sessions, transcribe the audio, and summarize the transcription using the Google Gemini API.

## 2. Architecture & Components
*   **Manifest V3 Extension:** Core configuration.
*   **Popup UI (HTML/CSS/JS):** Manages Gemini API key input and displays saved meeting summaries.
*   **Content Script (`content.js`):** Injected into `https://meet.google.com/*` to place a "Record Muse" button on the Meet control bar and send messages to the background script.
*   **Background Script (`background.js`):** Handles extension lifecycle and coordinates with the Offscreen Document (or Content Script) for recording.
*   **Offscreen Document (Required for MV3 Audio Recording):** Captures tab audio using `navigator.mediaDevices.getDisplayMedia()`.
*   **Gemini API Integration:** Sends base64-encoded audio to Gemini 1.5 Flash for transcription, then sends the transcript back for summarization.

## 3. Step-by-Step Implementation Steps

### Phase 1: Setup & Manifest
1.  Initialize project directory.
2.  Create `manifest.json` (Manifest V3).
3.  Add necessary permissions: `storage`, `scripting`, `tabs`, `activeTab`, and potentially `offscreen` (for audio capture in MV3).

### Phase 2: Popup Interface
1.  Create `popup.html` with:
    *   API Key input field + Save button.
    *   Container to list saved summaries.
2.  Create `popup.js` to:
    *   Save/Retrieve the API key using `chrome.storage.local`.
    *   Fetch and render summaries from `chrome.storage.local`.

### Phase 3: Content Script (The Button)
1.  Create `content.js`.
2.  Implement DOM observer to wait for the Google Meet control bar to render.
3.  Inject a custom `<button id="muse-record-btn">Record Muse</button>`.
4.  Add click listener to send `START_RECORDING` and `STOP_RECORDING` messages to the extension backend.

### Phase 4: Audio Capture & Background Logic
1.  Create `background.js` to listen for messages from `content.js`.
2.  **CRITICAL:** Implement an Offscreen Document (`offscreen.html` & `offscreen.js`) to handle the actual `MediaRecorder` logic, as Manifest V3 service workers cannot directly access `navigator.mediaDevices`.
3.  Capture tab audio and save it as a Blob/Base64 string when recording stops.

### Phase 5: Gemini API Integration
1.  Retrieve the saved Gemini API key.
2.  Send the recorded audio file to the Gemini 1.5 Flash endpoint for transcription.
3.  Receive the text transcript.
4.  Send a second prompt to Gemini with the transcript asking for: Summary, Action Items, and Key Decisions formatted as JSON.
5.  Parse the JSON response.

### Phase 6: Storage & Review
1.  Save the resulting JSON object (with a timestamp) to `chrome.storage.local`.
2.  Ensure `popup.js` correctly reads and updates the UI with the new data.
